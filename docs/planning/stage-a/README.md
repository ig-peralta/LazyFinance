# Stage A — financial-core validation

Stage A establishes whether LazyFinance's financial model can explain the
[J1–J5 journeys](../../product/user-journeys.md#stage-a---core-financial-understanding)
using representative CLP data. It validates the meaning of balances, spending,
internal movements, budgets, savings targets and income before relying on a bank
adapter. It is not a claim of a finished financial-management product.

## Scope and recorded outcome

The [Linear backlog snapshot](../snapshots/backlog-2026-11-02.md#sprint-a-stage-a--financial-core-validation)
contains 19 Stage A issues, all recorded Done at extraction. LAZ-18 records the
bounded financial-core GO decision; LAZ-15 records the missing-core-flow review
and Stage B handoff. The [closure record](closure.md) preserves the worklist,
gate baseline and provenance, while the [documentary retrospective](retrospective.md)
distinguishes recorded evidence from proposals for team review.

The accepted boundary includes target-only savings goals, not invented measured
contributions. Live banking, wider management flows and the first-party agent
were not certified by this gate. The [Stage B workstreams](../stage-b/README.md)
carry the subsequent product work.
